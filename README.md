# CyberKit Pro - Security Tools Suite

![CyberKit Pro Logo](frontend/assets/logo.png)

A comprehensive cybersecurity toolkit providing various tools for security analysis, testing, and protection.

## 🛠️ Features

CyberKit Pro offers a suite of web-based security tools:

- **Port Scanner**: Scan network ports for open services and vulnerabilities
- **Hash Generator**: Generate and verify cryptographic hashes
- **Encryption/Decryption**: Secure data using various encryption algorithms
- **Log Analyzer**: Analyze log files for security incidents and patterns
- **Password Cracker**: Attempt to recover passwords from their hash values
- **Web Crawler**: Crawl websites to discover links and analyze site structure
- **Phishing Detector**: Analyze URLs and websites for potential phishing threats

## 🚀 Getting Started

### Prerequisites

- Python 3.8+
- Node.js (for frontend development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/cyberkit-pro.git
cd cyberkit-pro
```

2. Set up the backend:
```bash
cd backend
pip install -r requirements.txt
python app.py
```

3. Set up the frontend (in a separate terminal):
```bash
cd frontend
npm install
npm start
```

4. Access the application at `http://localhost:5000`
